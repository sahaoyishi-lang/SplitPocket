# 💰 PocketSplit — Personal Finance & Expense Dashboard

PocketSplit is a sleek, modern personal finance and expense-tracking web application designed with minimalist aesthetics, real-time analytics, and instant local responsiveness.

## ✨ Key Features

- **📊 Comprehensive Financial Analytics**: Real-time tracking of total balance, monthly income, expenses, and savings rate.
- **💳 Digital Card & Account Management**: Interactive digital cards, balance allocation, and credit limit tracking.
- **🏷️ Smart Expense Segregation**: Categorize spending (Groceries, Tech, Dining, Utilities, Entertainment, etc.) with custom tags.
- **📷 UPI & QR Code Scanner**: Integrated camera and QR-code scanner with intelligent auto-categorization.
- **🎯 Dynamic Budget Limits**: Visual progress indicators and warnings when approaching budget limits.
- **🌓 Light & Dark Theme**: Hand-tailored color themes with fluid CSS variables and smooth transitions.
- **💾 Local Storage Persistence**: Your financial data stays private and stored directly in your browser.
- **📱 Fully Responsive**: Seamless experience across mobile phones, tablets, and widescreen desktop monitors.

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5 with ARIA accessibility labels
- **Styling**: Vanilla CSS3 (Custom Properties, Flexbox, CSS Grid, Glassmorphism, Micro-animations)
- **Logic**: Vanilla ES6+ JavaScript (LocalStorage API, HTML5 Canvas Charts, QR Scanner engine)
- **External CDN Utilities**:
  - [Google Fonts](https://fonts.google.com/) (Plus Jakarta Sans & JetBrains Mono)
  - [html5-qrcode](https://github.com/mebjas/html5-qrcode) (Camera scanner)
  - [Google Identity Services](https://developers.google.com/identity)

## 📦 How to Run Locally

No build tools or package managers required!

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).
3. Alternatively, serve with any local server (e.g. VS Code Live Server, Python `python -m http.server 8000`).
